6. Project report — two formats

The journey automatically informs two report views: an accessible learning summary and a technical record.

LIVING DOCUMENT
INTRODUCTORY REPORT

Project aim, what I learned, photos/videos of my work, challenges, final result and reflection — written in student-friendly language.

TECHNICAL PROJECT REPORT

Abstract, requirements, block/circuit diagrams, BOM, pin mapping, algorithm, source code, test cases, results and references.
